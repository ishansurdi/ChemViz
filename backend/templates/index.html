📡 Available Endpoints

Authentication

POST /api/auth/register/ (Use API tester below)
POST /api/auth/login/ (Use API tester below)

Datasets

POST /api/datasets/upload/ (Requires auth)
GET /api/datasets/history/ (Requires auth)

Analytics (Latest Dataset)

GET /api/summary/ (Requires auth)
GET /api/data/ (Requires auth)
GET /api/report/ (PDF Download, requires auth)

Admin & Health

GET /admin/ (Django Admin Panel)
GET /api/health/ ✓ Click to test!

🚀 Test the API

Option 1: Open the interactive API tester:

Open API Tester →

Option 2: Test with curl:

curl http://127.0.0.1:8000/api/health/

Option 3: Register via curl:

curl -X POST http://127.0.0.1:8000/api/auth/register/ \
  -H "Content-Type: application/json" \
  -d '{"username":"test","email":"test@example.com","password":"Test@1234","password2":"Test@1234"}'
